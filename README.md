# Knowledge Base Platform

A full-stack knowledge base application built with React, Node.js, Express, and MongoDB.

## Features

- Category → Group → Article hierarchy
- JWT Authentication
- Protected Admin Routes
- Article CRUD Operations
- REST API Architecture
- MongoDB Database Integration

## Tech Stack

- React
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication

## Status

Currently under active development. Authentication, article management, and admin functionality have been implemented.
